## Quick Pitch
Nexus is a modern, secure platform that connects entrepreneurs and investors in one intuitive ecosystem — turning visionary ideas into fundable, scalable ventures. Think beautiful pitch pages, curated deal flow, secure communication, and data-driven insights — all in one place.

---

## Why Nexus? (At a glance)
- 🚀 Founder-first profiles and milestone timelines  
- 🔍 Curated deal discovery with smart filters  
- 🔒 End-to-end secure communications and document sharing  
- 🤝 Built-in collaboration flows between founders and investors  
- 📈 Analytics to measure traction and pitch performance

---

## How Nexus Works
- For Entrepreneurs: Create a profile, publish pitch decks and milestones, receive interest and manage investor interactions.  
- For Investors: Browse curated startups, filter by domain/stage, view metrics, message founders, and manage opportunities.  
- Communication: Encrypted messaging, secure file exchange, and clear funding workflows to keep negotiations transparent and auditable.

---

## Core Features
- 🧭 Unified Dashboards — for founders and investors.  
- 💡 Multimedia Pitch Pages — images, video, docs, timelines.  
- 💬 Secure Messaging — private, encrypted conversations.  
- 📊 Analytics — engagement and traction metrics to inform decisions.  
- 🔐 Supabase Authentication — OTP-based secure login.  
- 🎨 Modern UI — responsive and accessible across devices.  
- 💸 Funding Tools — proposal management and progress tracking.

---

## Vision & Mission
- Vision: A world where every great idea finds the support it needs and every investor discovers the right opportunities.  
- Mission: Empower startups and streamline investment through a transparent, collaborative, and growth-focused platform.

---

## Impact
Nexus boosts visibility for early-stage teams, speeds up investor discovery, and fosters a community-driven ecosystem where innovation thrives globally.

---

## Roadmap (Short)
- Q3 — AI recommendations for investors, verified investor badges  
- Q4 — Mobile apps + Push notifications  
- Next — Mentorship & partnership programs, expanded analytics

---

## Get Started
- Clone the repo: git clone https://github.com/Nexus-lb/nexus
- Install: npm install  
- Dev: npm run dev  
- Env: set VITE_SUPABASE_URL & VITE_SUPABASE_ANON_KEY
